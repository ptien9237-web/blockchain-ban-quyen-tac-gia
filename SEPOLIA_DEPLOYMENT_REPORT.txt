3. BẰNG CHỨNG KIỂM TRA LỆNH TRIỂN KHAI THỰC TẾ
================================================================================

Khi chạy lệnh kiểm tra kịch bản triển khai Sepolia:
    npm run contracts:deploy:sepolia

Kết quả thực tế từ Hardhat:
    ================================================================================
    DEPLOYING BOOK COPYRIGHT REGISTRY TO NETWORK: SEPOLIA
    ================================================================================
    Deployment failed: Error: No deployer account configured for network sepolia
        at main (C:\...\scripts\deploy.cjs:12:11)

Đánh giá:
- Hệ thống phát hiện chính xác ví deployer chưa được cấu hình, ngăn chặn việc broadcast giao dịch rác hoặc dùng sai mạng.
- Script deploy có điều kiện bảo vệ nghiêm ngặt (dòng 24-28 trong `scripts/deploy.cjs`):
  Nếu ví có số dư 0 SepoliaETH, script sẽ lập tức dừng lại với cảnh báo:
  "ERROR: Deployer account has 0 ETH on Sepolia testnet. Please fund your wallet with Sepolia ETH before deploying."

4. HƯỚNG DẪN DÀNH CHO NGƯỜI DÙNG ĐỂ TRIỂN KHAI LÊN SEPOLIA
================================================================================

Để đưa hệ thống lên mạng công khai Ethereum Sepolia, người dùng chỉ cần thực hiện 4 bước sau:

Bước 1: Chuẩn bị Ví và lấy SepoliaETH miễn phí:
    - Tạo một tài khoản ví MetaMask mới dành riêng cho thử nghiệm (KHÔNG dùng ví chứa tài sản thật).
    - Sao chép địa chỉ ví (ví dụ: 0x1234...abcd).
    - Nhận SepoliaETH miễn phí từ các vòi (faucets) công khai uy tín:
      * Google Cloud Web3 Faucet: https://cloud.google.com/application/web3/faucet/ethereum/sepolia
      * Alchemy Sepolia Faucet: https://www.alchemy.com/faucets/ethereum-sepolia
      * QuickNode Sepolia Faucet: https://faucet.quicknode.com/ethereum/sepolia
      * PoW Faucet: https://sepolia-faucet.pk910.de
    - Đảm bảo ví có ít nhất 0.05 SepoliaETH để chi trả phí gas.

Bước 2: Cấu hình biến môi trường trong file `.env`:
    Mở file `.env` tại thư mục gốc dự án và bổ sung các dòng sau:
    --------------------------------------------------------------------------------
    # Ethereum Sepolia Testnet Configuration
    BLOCKCHAIN_NETWORK=sepolia
    BLOCKCHAIN_CHAIN_ID=11155111
    SEPOLIA_RPC_URL=https://ethereum-sepolia-rpc.publicnode.com
    # Hoặc RPC từ Alchemy/Infura: https://eth-sepolia.g.alchemy.com/v2/YOUR_API_KEY
    SEPOLIA_PRIVATE_KEY=your_private_key_without_0x_prefix
    ETHERSCAN_API_KEY=your_etherscan_api_key_for_contract_verification_optional
    --------------------------------------------------------------------------------
    (CẢNH BÁO BẢO MẬT: Không commit file .env chứa private key lên Git hoặc chia sẻ cho người khác).

Bước 3: Thực hiện lệnh Triển khai:
    Chạy lệnh:
        npm run contracts:deploy:sepolia

    Lệnh này sẽ:
    1. Kết nối tới Sepolia RPC.
    2. Triển khai hợp đồng `BookCopyrightRegistry.sol`.
    3. Cấp vai trò `DEFAULT_ADMIN_ROLE` và `REGISTRAR_ROLE` cho ví deployer.
    4. Tự động ghi lại địa chỉ contract thực tế và TxHash vào:
       - `deployments/sepolia.json`
       - `src/contracts/deployedAddresses.json`
       - `server/contracts/deployedAddresses.json`

Bước 4: Xác minh mã nguồn trên Sepolia Etherscan (Tùy chọn):
    Sau khi triển khai thành công, chạy lệnh:
        npx hardhat verify --network sepolia <CONTRACT_ADDRESS> <DEPLOYER_ADDRESS>
