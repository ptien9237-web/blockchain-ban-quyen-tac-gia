## Decisions
- Used Vanilla CSS with CSS variables over TailwindCSS (per user instruction to avoid Tailwind).
- Replaced Web3/Crypto aesthetic with an Editorial/Archival aesthetic to meet the "Library First" mandate.
- Implemented mock functionality for file hashing and blockchain interactions to satisfy MVP requirements.
- Implemented I18n and Theme as React Contexts mapped to LocalStorage and class mutations to avoid third party bloat and ensure fast execution. Data contents (book descriptions, names, hashes) remain strictly untranslated to preserve integrity.
