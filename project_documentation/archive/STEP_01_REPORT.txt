2. CÁC CHỨC NĂNG HOẠT ĐỘNG THỰC TẾ
- Endpoint kiểm tra sức khỏe (/api/health) kiểm tra kết nối CSDL SQL Server và thời gian phản hồi.
- API đăng ký (/api/auth/register) xác thực dữ liệu đầu vào, băm mật khẩu bằng bcrypt, ghi nhận vào dbo.Users và dbo.UserRoles.
- API đăng nhập (/api/auth/login) kiểm tra mật khẩu đã băm, tạo phiên trong dbo.Sessions, cấp cookie HttpOnly.
- API đăng xuất (/api/auth/logout) thu hồi phiên trong dbo.Sessions và xóa cookie.
- API lấy thông tin cá nhân (/api/auth/me, /api/users/profile) được bảo vệ bằng middleware kiểm tra phiên thật.
- API cập nhật thông tin (/api/users/profile) cho phép đổi tên hiển thị và avatar, không cho phép đổi email/role.
- API đăng ký tác giả (/api/users/author-profile) tạo bản ghi trong dbo.AuthorProfiles và tự động cấp vai trò AUTHOR.
- Middleware RBAC (requireRole) chặn thành công người dùng thường truy cập tài nguyên của AUTHOR hoặc ADMIN.
- Giao diện web kết nối trực tiếp với backend qua proxy Vite, hỗ trợ đầy đủ tiếng Anh và tiếng Việt.

3. TRẠNG THÁI KẾT NỐI DATABASE
- Trạng thái: PASS (ĐÃ KẾT NỐI THẬT).
- Máy chủ CSDL: Microsoft SQL Server 2025 (RTM) - 17.0.1000.7 (X64) tại localhost.
- Tên CSDL: BookChainLibrary.
- Người dùng ứng dụng: bookchain_dev (được phân quyền db_datareader, db_datawriter).
- Độ trễ kết nối trung bình: ~300ms - 500ms qua connection pool.
- Bằng chứng dữ liệu: Đã kiểm tra trực tiếp qua lệnh SQL Server, các bảng Users, Roles, UserRoles, Sessions và AuthorProfiles đều đã lưu trữ bản ghi thực tế từ quá trình chạy thử.
