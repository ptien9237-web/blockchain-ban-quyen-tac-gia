- [PASS] 1. Quản lý tác phẩm (Book Management):

  * Tự động liên kết tác giả tạo sách làm PRIMARY_AUTHOR với thứ tự hiển thị DisplayOrder = 1 qua Transaction.

  * Lấy danh sách tác phẩm của tác giả hiện tại (My Books).
  * Lấy chi tiết sách bao gồm danh sách tác giả, phiên bản tệp hiện hành.
  * Cập nhật thông tin tác phẩm có kiểm tra quyền sở hữu IDOR nghiêm ngặt.
  * Chuyển đổi trạng thái xuất bản (DRAFT, PUBLISHED, UNLISTED, ARCHIVED) theo đúng quy tắc nghiệp vụ.
- [PASS] 2. Quản lý nhiều tác giả (Multi-Author Management):
  * Hỗ trợ quan hệ nhiều-nhiều giữa sách và hồ sơ tác giả qua bảng dbo.BookAuthors.
  * Hỗ trợ các vai trò đóng góp: PRIMARY_AUTHOR, CO_AUTHOR, EDITOR, TRANSLATOR.
  * Kiểm tra tác giả thêm vào phải tồn tại trong dbo.AuthorProfiles.
  * Chống tạo quan hệ trùng lặp (Duplicate check).
  * Chỉ tác giả sở hữu sách mới có quyền mời hoặc thêm đồng tác giả.
- [PASS] 3. Tầng lưu trữ tệp và quản lý phiên bản (File Storage & Versioning):
  * Xây dựng tầng lưu trữ trừu tượng IStorageProvider với triển khai LocalStorageProvider.
  * Lưu trữ an toàn tại thư mục máy chủ (storage/books/) với Safe File Key YYYYMMDD_<uuid>.<ext>, chống Path Traversal.
  * Tiếp nhận file tải lên qua Multer (PDF, EPUB, TXT) với giới hạn kích thước an toàn 50MB.
  * Quản lý phiên bản tệp tăng tiến (VersionNumber = MAX + 1) trong ACID Transaction trên SQL Server.
  * Đảm bảo ràng buộc duy nhất một phiên bản hiện hành (IsCurrent = 1) cho mỗi tác phẩm.
  * Xem toàn bộ lịch sử phiên bản tệp của tác phẩm.
- [PASS] 4. Tính toán và đối soát SHA-256 thực tế (Authentic SHA-256 Calculation & Verification):
  * Backend tính mã băm SHA-256 trực tiếp từ chuỗi byte nhị phân của tệp nhận được bằng crypto.createHash('sha256').
  * Không tin mã hash do client gửi lên; lưu trữ chuỗi hexadecimal 64 ký tự chuẩn vào dbo.BookFiles.Sha256Hash.
  * Endpoint đối soát toàn vẹn (/api/books/:id/files/:fileId/verify) đọc lại byte tệp trên đĩa máy chủ và so khớp với CSDL.
  * Phát hiện chính xác trường hợp tệp bị sửa đổi nội dung trên đĩa (hash mismatch: verified = false).
  * Hỗ trợ tra cứu Sổ cái CSDL theo mã băm SHA-256 (/api/books/verify-hash/:hash).
- [PASS] 5. Kiểm soát quyền đọc và tải file (Access Level Enforcement):
  * Hỗ trợ 3 cấp độ: PRIVATE, PUBLIC_READ, PUBLIC_DOWNLOAD.
  * PRIVATE: Chặn hoàn toàn độc giả bên ngoài (HTTP 403), chỉ cho phép tác giả của sách hoặc Admin đọc/tải.
  * PUBLIC_READ: Cho phép độc giả đọc trực tuyến (inline stream) qua Archival Reader; chặn tải file gốc (HTTP 403).
  * PUBLIC_DOWNLOAD: Cho phép độc giả vừa đọc trực tuyến vừa tải file gốc về máy (attachment stream).
  * Kiểm tra quyền chặt chẽ tại backend, không chỉ ẩn nút trên giao diện.
- [PASS] 6. Tích hợp giao diện Frontend:
  * Trang Discover (/discover): Hiển thị danh mục sách thật từ CSDL, tìm kiếm, lọc ngôn ngữ, trạng thái rỗng và lỗi.
  * Component BookCard: Hiển thị bìa sách thật, danh sách tác giả thật, huy hiệu mã băm SHA-256 thật.
  * Trang BookDetail (/book/:id): Hiển thị thông tin sách thật, Modal "Archival Reading Room" đọc PDF trực tiếp,
    trình chọn phiên bản (version switcher), nút tải sách theo quyền, nút kiểm tra tính toàn vẹn SHA-256 trên đĩa máy chủ.
  * Trang Verify (/verify): Người dùng chọn tệp cục bộ bất kỳ, tính mã băm SHA-256 tức thì bằng Web Crypto API,
    tra cứu đối chiếu với Sổ cái SQL Server và kiểm tra tính toàn vẹn với tệp lưu trữ của máy chủ.
  * Trang Profile (/profile): Khu vực Quản lý tác phẩm cho tác giả với danh sách sách của mình, Modal tạo sách mới,
    Modal tải lên phiên bản mới (chọn AccessLevel), Modal thêm đồng tác giả, nút chuyển đổi trạng thái xuất bản.
  * Giữ trọn vẹn thẩm mỹ "Archival Reading Room", chế độ Sáng/Tối và song ngữ EN/VI.

4. DANH SÁCH API HOÀN THIỆN ĐẾN HẾT BƯỚC 02
- GET    /api/health                             - Kiểm tra trạng thái máy chủ và kết nối SQL Server
- POST   /api/auth/register                     - Đăng ký tài khoản thành viên
- POST   /api/auth/login                        - Đăng nhập và tạo phiên
- POST   /api/auth/logout                       - Đăng xuất và thu hồi phiên
- GET    /api/auth/me                           - Lấy thông tin tài khoản hiện tại
- GET    /api/users/profile                     - Lấy hồ sơ cá nhân
- PUT    /api/users/profile                     - Cập nhật thông tin hồ sơ
- POST   /api/users/author-profile              - Đăng ký bút danh tác giả
- GET    /api/books                             - Danh sách sách công khai (tìm kiếm từ khóa, lọc ngôn ngữ)
- GET    /api/books/my                          - Danh sách sách của tác giả hiện tại
- GET    /api/books/:id                         - Chi tiết sách (kèm tác giả và phiên bản tệp hiện hành)
- POST   /api/books                             - Tạo sách mới (Transactional: Book + Primary Author)
- PUT    /api/books/:id                         - Cập nhật metadata sách (kiểm tra quyền sở hữu IDOR)
- PATCH  /api/books/:id/status                  - Cập nhật trạng thái xuất bản
- POST   /api/books/:id/authors                 - Thêm đồng tác giả cho sách
- POST   /api/books/:id/files                   - Tải lên phiên bản tệp mới (tính SHA-256 byte thật, tăng version)
- GET    /api/books/:id/files                   - Lấy lịch sử phiên bản tệp của sách
- GET    /api/books/:id/files/:fileId           - Xem metadata tệp phiên bản
- GET    /api/books/:id/files/:fileId/read      - Đọc trực tuyến tệp sách (stream inline PDF)
- GET    /api/books/:id/files/:fileId/download  - Tải tệp sách về máy (chặn nếu mức truy cập là PUBLIC_READ)
- GET    /api/books/:id/files/:fileId/verify    - Đối soát toàn vẹn SHA-256 giữa tệp trên đĩa và CSDL
- GET    /api/books/verify-hash/:hash           - Tra cứu tác phẩm theo mã băm SHA-256 từ Sổ cái hệ thống
